# Changelog

Player-facing changes for each Isekai Hero release are recorded here.

## [Unreleased]

## [v0.6.0-alpha] - 2026-07-15

### Changed

- Moved release builds and packaging to a repeatable cloud workflow.
- Added automatic version, changelog, and package validation before publishing.
- Improved release reliability without changing gameplay or balance.

## [v0.5.0-alpha] - 2026-07-15

### Added

- Added the EXP and Level combat core, including Vigor rewards when leveling up.
- Added The System starter relic and the rebuilt starter deck with Grind and Danger Sense.
- Expanded the early-alpha pool to 22 cards, including Shield Bash, Duel, and Degenerate Tactics.

### Changed

- Updated character UI art, the map marker, card portraits, and relic art.
- Refined the mod description around the EXP/Level, Exploit, Quest, Job, and Cheat Skill identity.
